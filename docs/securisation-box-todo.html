Sécurisation de la box CleverRemote

Todo list : chaîne de confiance matérielle (OTP + Secure Boot + LUKS + age). Raspberry Pi 4B rev 1.5, Debian 12, systemd 252, MongoDB en localhost.

0 / 0 tâches

Architecture cible

OTP du SoC (clé 256 bits unique par box, gravée dans le Pi)
   │   protégée par Secure Boot (seul un boot.img signé peut la lire)
   ├──► LUKS : rootfs + données Mongo chiffrées, déverrouillées au boot via la clé OTP
   └──► age  : identité age dérivée de la clé OTP → déchiffre .env.age en RAM
                 └──► service systemd durci, utilisateur dédié, secrets jamais sur disque
Mongo tourne en localhost : sans LUKS, une carte SD volée donne accès direct aux données, même si le .env est chiffré. Les phases 4 et 5 sont celles qui apportent la sécurité maximale.
